# Covibes Studio media

The screenshots show **Covibes V1**, the project of the approved Studio design scene, opened in the running application in the architecture phase. Alex, Sam and Robin plan together with the moderator and the backend, critic and data agents; the conversation, decisions, criteria, architecture board, proposal and plan belong to the same local project. The agent messages were seeded for the demonstration, and the board overview is hidden until it has the Studio styling.
