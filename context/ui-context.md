# UI Context

## New design mandate (2026-11-17)

The owner explicitly requires a completely new, unique modern design and has
rejected using the existing Covibes design as a reference. Previous token values,
component styling, layouts and handoffs are superseded. Historical versions stay
in Git; they are not inputs to the new design.

The active new handoff is `context/design/next/README.md`, with an independent
interactive prototype beside it. Spec 55 implements it across the application;
spec 49 shares its loading and responsive layout contracts. The design team is
researching current repositories and web applications, with dated evidence in
`context/research/`. Popularity signals and observed UI quality are distinct.

Until that handoff is ready, engineering proceeds on behavior and data contracts.
Do not invent a replacement by adapting the old token palette or old layouts.

## Requirements that remain

- German and English through i18n.
- Keyboard access, visible focus, semantic controls, sufficient contrast, reduced
  motion, and responsive behavior across phone, tablet and desktop.
- Authorship, permission boundaries, explicit approval of Git actions, and truthful
  loading, persistence and error states.
- Planning, canvas, decisions, conversations, exports and agents remain available;
  their information architecture may change under the new handoff.
