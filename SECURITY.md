# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [@JulianRudrich](https://github.com/JulianRudrich). Include the affected commit, steps to reproduce the issue, and its potential impact. Avoid including credentials or private project content in the report.

## Supported versions

Covibes is in development. Security fixes are applied to `main`. For self-hosting configuration, see the [deployment guide](deploy/README.md).
